# دردشة — تطبيق Android أصلي (Kotlin + Jetpack Compose)

نسخة أصلية (Native) من `chat-v46.html` — **بدون WebView**. تتصل بنفس مشروع Supabase
(نفس الحسابات والجداول والـ buckets) فتعمل مع نسخة الويب جنباً إلى جنب.

## البناء عبر GitHub Actions (من KlencodIDE)
1. ارفع محتوى هذا المجلد إلى مستودع GitHub (الفرع `main`).
2. شغّل workflow باسم **Build Android APK** (يدوي فقط: Actions ← Build Android APK ← Run workflow).
3. حمّل الملف من Artifacts: `dardasha-debug-apk`.

الاعتماديات: Kotlin 2.0.21 · AGP 8.7.3 · Gradle 8.9 · Compose BOM 2024.12.01 · supabase-kt 3.0.3.
`minSdk 26` / `targetSdk 35`. لا يحتاج Gradle wrapper (الـ workflow يثبّت Gradle بنفسه).

## الميزات المنقولة
- تسجيل الدخول / إنشاء حساب (جلسة محفوظة)
- قائمة المحادثات + بحث + عدّاد غير المقروء + علامات الإرسال/القراءة
- محادثة فورية (Realtime): نص، صور (ضغط + عرض كامل)، رسائل صوتية (تسجيل m4a وتشغيل)
- رد على رسالة، تعديل، حذف للجميع / حذف عندي، تفاعلات إيموجي
- متصل الآن / آخر ظهور / "يكتب الآن..." (نفس قناة `room` في الويب)
- بدء محادثة جديدة بالبحث عن اسم مستخدم، حظر / إلغاء حظر
- الملف الشخصي: صورة، "حول"، تسجيل الخروج
- إشعارات محلية عند وصول رسالة والتطبيق في الخلفية (والعملية حيّة)
- واجهة RTL عربية بنفس ألوان نسخة الويب

## ميزات مضافة (v1.1)
- **إرسال المستندات**: أي ملف حتى 20MB (رفع إلى bucket `chat-files`)، والضغط على الملف يفتحه بتطبيق مناسب
- **مشاركة الموقع**: رابط خرائط داخل الرسالة مع بطاقة موقع (بعد تأكيد المستخدم)
- **تثبيت** (حتى 3) و**أرشفة** و**كتم** المحادثات: ضغط مطوّل على المحادثة في القائمة، أو من قائمة ⋮ داخل المحادثة
  - المكتومة: بلا إشعارات وعدّاد رمادي · المؤرشفة تعود تلقائياً عند وصول رسالة (إلا إذا كانت مكتومة)
- **رسائل بنجمة**: ضغط مطوّل على رسالة ← «تمييز بنجمة»، وشاشة «الرسائل المميّزة» من قائمة ⋮ في الرئيسية

> **مهم:** شغّل `supabase/features.sql` مرة واحدة في Supabase ← SQL Editor ليُنشئ جداول
> `chat_prefs` و`message_stars` وbucket `chat-files`. التثبيت/الأرشفة/الكتم/النجوم تعمل محلياً حتى بدونه،
> لكنها لا تتزامن بين الأجهزة، ورفع المستندات يحتاجه.
> إن كان bucket المستندات في نسخة الويب باسم آخر فغيّر `Repo.FILES_BUCKET`.

## ميزات مضافة (v1.2)
- **إعادة توجيه**: ضغط مطوّل ← «إعادة توجيه» ← اختيار عدة محادثات. الصور/الصوت/الملفات تُنسخ وتُرفع تحت مسار المستلم الجديد (ليعمل التحميل مع صلاحيات التخزين)، وتظهر عبارة «↪ معاد توجيهها»
- **صور «مرة واحدة»**: زر «① مرة واحدة» عند تجهيز الصورة. المستلم يفتحها مرة واحدة فقط (شاشة محمية من لقطات الشاشة `FLAG_SECURE`) ثم تُسجَّل `viewed_at` ويحذف جهاز المرسِل الملف من التخزين
- **رسائل مؤقتة**: من ⋮ ← «الرسائل المؤقتة» (24 ساعة / 7 أيام / 90 يوماً). الرسائل الجديدة تحمل `expires_at` وتختفي فعلياً لدى الطرفين، ويحذفها جهاز المرسِل من القاعدة والتخزين. المؤقّت يتزامن لحظياً عبر `chat_timers`
- **الملف الشخصي الموسّع**: الاسم المعروض، حول، نبذة (300 حرف)، المدينة، تاريخ الميلاد، حتى 5 روابط (تُتحقق وتُفتح بالمتصفح، مع أيقونة المنصة تلقائياً)
- **شاشة معلومات جهة الاتصال**: اضغط على اسم/صورة الشخص في المحادثة: صورة كبيرة، حول، نبذة، روابط، كتم، مؤقّت، حظر
- **روابط قابلة للضغط** داخل الرسائل النصية

- **الإعدادات (v1.14)** — من القائمة ⋮ في الشاشة الرئيسية ← «الإعدادات»، وكلها محفوظة على الجهاز:
  - **الحساب**: تعديل الملف الشخصي، الحسابات المتعددة، الرسائل المميّزة، تسجيل الخروج.
  - **الخصوصية**: إخفاء «متصل/آخر ظهور»، إشعارات القراءة، مؤشّر «يكتب...»، منع لقطات الشاشة، قائمة المحظورين.
  - **الدردشات**: حجم الخط (مع معاينة)، نمط الخلفية، Enter للإرسال، أرشفة/حذف كل المحادثات.
  - **الإشعارات**: تفعيل/تعطيل، معاينة الرسالة، الصوت، الاهتزاز، إشعار تجريبي، اختصار لإعدادات النظام.
  - **المظهر**: داكن / فاتح / حسب النظام، و6 ألوان تمييز.
  - **التخزين والبيانات**: حجم الملفات المؤقتة ومسحها، التنزيل التلقائي للصور (دائماً / Wi-Fi / أبداً)، جودة الصور المرسلة، إحصاءات.
  - **المساعدة**: الإصدار، مشاركة التطبيق، معلومات التطبيق في النظام، إعادة ضبط الإعدادات.

> **مهم (v1.2):** شغّل `supabase/features_v2.sql` مرة واحدة في SQL Editor (يضيف أعمدة `display_name, bio, city, birthday, links` لجدول `profiles`، ويضمن `chat_timers` وأعمدة الرسائل). بدونه لن يُحفظ الملف الشخصي الموسّع.

## الحسابات المتعددة (v1.9)
- أضف أكثر من حساب على نفس الجهاز والتنقّل بينها دون كلمة مرور، مثل فيسبوك (حتى 5 حسابات).
- **التبديل:** قائمة ⋮ في الشاشة الرئيسية ← «الحسابات»، أو من شاشة «الملف الشخصي» ← قسم «الحسابات».
- **إضافة حساب:** «إضافة حساب» ← سجّل الدخول أو أنشئ حساباً (الحساب الحالي يبقى محفوظاً، وزر الرجوع يلغي العملية).
- **الإزالة:** ✕ بجانب الحساب، أما «تسجيل الخروج» فيخرج من الحساب الحالي فقط ثم ينتقل لحساب محفوظ آخر.
- كل حساب له بياناته المحلية المنفصلة (المسودات، المخفي، التثبيت، النجوم، المؤقّت).
- الإشعارات: الضغط على إشعار يخصّ حساباً آخر يبدّل إليه ثم يفتح المحادثة.
> **مهم:** شغّل `supabase/accounts.sql` مرة واحدة كي تصل إشعارات كل الحسابات المحفوظة، ثم أعد نشر الدالة `send-push`
> (أُضيف إليها الحقل `receiver`). بدونهما تصل الإشعارات للحساب النشط فقط.

## إشعارات فورية (FCM) — v1.6
إشعارات تصل حتى والتطبيق مغلق، عبر Firebase + Supabase Edge Function. **تحتاج إعداداً لمرة واحدة**: اتبع `supabase/PUSH_SETUP.md`
(ملف `google-services.json` + تشغيل `supabase/push.sql` + نشر الدالة `send-push`). بدون الإعداد يُبنى التطبيق ويعمل بإشعاراته المحلية السابقة.

## ملاحظات
- مفتاح Supabase في `data/Supa.kt` هو نفس المفتاح العام (publishable) الموجود في ملف HTML.
- الـ buckets المستخدمة: `chat-images` · `chat-audio` · `avatars`.
- لم يُجرَّ بناء فعلي أثناء كتابة المشروع (لا شبكة في بيئة الكتابة)؛ إن ظهر خطأ تجميع أرسل لي نص الخطأ من سجل Actions وأصلحه فوراً.

## ميزات مضافة (v1.10)
- **تنسيق النص**: `*غامق*` و`_مائل_` و`~مشطوب~` داخل الرسائل (الروابط لا تتأثر).
- **معرض الوسائط**: معلومات جهة الاتصال ← «الوسائط والملفات والروابط»: تبويبات صور / ملفات / روابط (لا تشمل صور «مرة واحدة» ولا المحذوفة).
- **الرسائل غير المقروءة**: فاصل «N رسائل غير مقروءة» فوق أول رسالة جديدة، وفتح المحادثة ينتقل إليها تلقائياً إن كانت بعيدة (وزر النزول يحمل العدّاد).
- **صورة الملف الشخصي من القائمة الرئيسية**: الضغط على الصورة الصغيرة يعرضها كبيرة (الضغط المطوّل ما زال يحدد المحادثة).

## شاشات البداية (v1.11)
- **شاشة الترحيب**: تظهر عند عدم وجود حساب مسجّل (أول فتح أو بعد تسجيل الخروج)، زر «ابدأ» ينقلك لتسجيل الدخول/إنشاء الحساب، وزر الرجوع من شاشة الدخول يعيدك إليها.
- **الشاشة الافتتاحية (Splash)**: عند فتح التطبيق وفيه حساب مسجّل يظهر الشعار مع حركة خفيفة نحو ثانية ونصف ثم تدخل الرئيسية (يظهر شريط تحميل إن تأخّر استرجاع الجلسة).

## إصلاح (v1.12)
- مهلة طلبات Supabase رُفعت من 10 إلى 40 ثانية (كانت تسبّب «Request timeout has expired» على الشبكات البطيئة)، ورسائل أخطاء الاتصال صارت بالعربية.

## التثبيت فوق النسخة القديمة (v1.12)
- أُضيف مفتاح توقيع ثابت `app/dardasha.keystore` (يجب رفعه إلى GitHub مع المشروع، ولا تحذفه). كل بناء بعد الآن يُوقَّع بنفس المفتاح فيُثبَّت فوق السابق كتحديث وتبقى الجلسة.
- **مرة واحدة فقط**: النسخة المثبّتة حالياً موقّعة بمفتاح عشوائي قديم، فاحذفها يدوياً ثم ثبّت الجديدة. بعدها كل تحديث يُثبَّت فوقها مباشرة.
- ارفع `versionCode` في `app/build.gradle.kts` مع كل نسخة جديدة (الآن 8) وإلا يرفض أندرويد التحديث.
